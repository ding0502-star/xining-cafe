# 西寧咖啡 · Xining Cafe

Godot 3D 咖啡店經營遊戲的 GitHub Pages 發布版本。

## 發布

將這個資料夾的內容推送到 GitHub 儲存庫的 main 分支。在儲存庫 Settings → Pages → Build and deployment 選擇 GitHub Actions。此儲存庫的 Publish Xining Cafe 工作流程會發布 docs 裡的完整遊戲。

第一次上傳若尚未啟用 Pages，設定完成後可在 Actions → Publish Xining Cafe → Run workflow 重新發布。請使用工作流程回傳的正式網址。

## 遊玩

點「進入咖啡店」，載入後按「開始營業」。店員會自動製作並送餐，可調整售價、升級咖啡機、增加座位，並保存遊戲進度。

存檔只保存在目前瀏覽器的網站資料。GitHub Pages 與先前的 ChatGPT Sites 網址分屬不同網站，兩者存檔不會自動共用。清除網站資料會刪除存檔。

網頁版適用支援 WebGL 2、WebAssembly、DecompressionStream 的現代瀏覽器；小螢幕建議橫向遊玩。
